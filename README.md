# TPC — Two Pair Poker Camp

투페어 포커캠프의 소개 웹사이트와 사업기획안·코치 제안서입니다.

## 구성

- `index.html`: TPC 메인 소개 페이지
- `proposal/index.html`: 사업기획안 및 코치 제안서
- `docs/`: 기획 및 제안 관련 문서

## 로컬에서 확인하기

별도의 빌드 과정 없이 정적 웹 서버로 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

실행 후 `http://localhost:8000`에서 메인 페이지를, `http://localhost:8000/proposal/`에서 기획안을 확인할 수 있습니다.
